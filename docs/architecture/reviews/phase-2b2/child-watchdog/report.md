# Child-enforced renewable lease

Base: `f1d0526c5f60261f77e8a0c636f8474a5309826d`. Worktree: `/tmp/swarmforge-phase2b2-watchdog`, branch `phase2b2-child-watchdog`.

The original parent-only lease timer cannot execute while its supervisor event loop stalls. The original real-child counterexample leaves a 20s child running past its 10s lease. The corrected child receives numeric initial lease and immutable task deadlines in its explicitly allowlisted environment, fixed before spawn, and refuses missing, malformed or expired initial authority before work. Only validated supervisor renewals write bounded newline frames on the existing private stdin pipe. Child receipt checks both the previous lease and supplied absolute deadlines; buffered or late writes cannot reopen expiry. EOF/error remains fail closed. No cloud, storage, coordinator or arbitrary-workload changes were made.

The cross-process clock is Linux `/proc/uptime` (system uptime including suspend, documented in local `/usr/share/man/man5/proc.5.gz`). Its first field is shared between processes and has 10ms resolution. Parent conversion subtracts 20ms; child observations add 10ms, conservatively accounting for truncation. An unreadable/invalid clock refuses execution. Bun `process.hrtime.bigint()` is unsuitable here: the empirical parent-before/child/parent-after readings are 2995761/2497493/6691088, while corresponding host boot times are 485199.54/485199.55/485199.55. Wall time and process-relative origins never cross IPC.

The full requested duration remains a separate child timer. Lease expiry exits with code 4 and maps to cancelled, with durable journal identity retained until actual OS stop proof. Renewal writes await the pipe callback before updating authority; both provider and supervisor recheck previous expiry, and supervisor rechecks current run and durable stop state before publishing a renewal. The delayed callback regression fails without this final check and passes with it.

Behavioral evidence: the initial authority test suite against the immutable original child produced 1 pass / 9 fail. Corrected tests show a real child alive before the parent stalls, independently stopped afterward; delayed startup, missing/malformed initial authority, late renewal, full short-duration completion and parent EOF also pass. The actual supervisor stall test proves cancelled completion, retained journal, and confirmed OS stop. The callback-order regression produces 0 pass / 1 fail without the guard, and 1 pass / 0 fail with it. See preserved logs alongside this report.

This environment blocks actual pipe writes: a minimal Bun FileSink write throws `EPERM`; Node-compatible pipe writes lead to child EOF without delivering bytes. Therefore the 31s successful renewable workload, malformed renewal frames and buffered renewal cases remain asserted but are not green. The 31s test still requires code 0 and elapsed duration >=31000ms. Its valid renewal frame helper clamps the proposed lease to the immutable absolute task deadline; otherwise a late renewal would itself be malformed. No assertions were weakened and no tests were skipped for these gaps.
